# Kotlin Starter Kit (Next.js Edition)

Enterprise-grade SaaS Starter Kit migrasi ke Modern Stack (Next.js 15, React 19, Tailwind v4). Mencakup RBAC berbasis Capability (Cedar/OPA), Audit Log Event-Sourcing (HMAC Chaining), Notifikasi Multi-Channel Idempoten (Outbox + SSE), Manajemen Tim Hierarkis (Materialized Path), dan kini diperkaya fitur **Broadcast Engine (Blast ke Semua Member)** dengan scheduling, segmentasi dinamis, & observabilitas real-time.

## Menjalankan

```bash
npm install
npm run dev
```
